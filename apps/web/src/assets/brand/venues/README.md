# Изометрические иллюстрации заведений

Сюда кладём картинки залов партнёров для слайдов главной карусели.

Имя файла = id бренда из HomePage.vue (без префикса `b_`):

- `evos.png`
- `safia.png`
- `bellissimo.png`
- `bon.png`
- `oqtepa.png`, `maxway.png`, `lesailes.png`, `sushitime.png`, `korzinka.png`,
  `texnomart.png`, `idea.png`, `click.png`, `payme.png`

Формат: PNG/JPG/WEBP, ширина ~1200–1600px, изометрия на прозрачном или
однотонном фоне. Подхватываются автоматически (import.meta.glob) — если файла
нет, слайд рисует прежнюю плашку с логотипом.
