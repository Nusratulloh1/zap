# ZAP! — сплит-платежи (PWA MVP)

Групповая оплата счетов для Узбекистана: сканируешь QR на чеке, делишь счёт поровну / вручную / по позициям, друзья платят по ссылке, группа копит кэшбэк ×2. Бэкенда нет — приложение работает на мок-API с сид-данными, симулированной латентностью и «реальным временем».

**Стек:** Vue 3 (`<script setup>` + TS strict) · Vite + vite-plugin-pwa · Tailwind CSS · Pinia · vue-router · GSAP (моушен-система: пресс-фидбек, шиты с drag-to-dismiss, стаггеры) · embla-carousel (промо-карусель) · reka-ui · vue-sonner · qrcode · jsqr.

## Запуск

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # прод-сборка + service worker (vue-tsc, zero errors)
pnpm preview    # прод-превью
pnpm icons      # перегенерировать PWA-иконки/фавиконки из логотипа (src/assets/brand/logo)
```

PWA: устанавливается с главного экрана, после первой загрузки полностью работает офлайн (данные локальные, Google Fonts кэшируются CacheFirst).

## Демо-сценарий (golden path)

1. **Онбординг** — 3 сторис-слайда (тап — дальше, удержание — пауза) → «Начать».
2. **Телефон** — любой номер с нативной клавиатуры (маска «+998 90 123 45 67») → «Получить код».
3. **Код из SMS** — подойдут любые 6 цифр → придумайте PIN (дважды). **Запомните PIN** — им подтверждаются оплаты.
4. **Главная** — статы (кэшбэк 145 000, должники 633 000), группы, история сплитов.
5. **«Сплит»** → сканер с **реальной камерой** (getUserMedia + BarcodeDetector/jsQR): наведите на QR — ссылка `zap.uz/s/…` откроет сплит, любой другой QR откроет демо-счёт Bellissimo. Камера требует HTTPS или localhost; без камеры — карточка «Нет доступа к камере» с кнопкой **«Демо-чек»** → счёт #481 на 1 200 000 → **«Разделить»**.
6. **«С кем делим?»** — Али и Бек уже в списке; включите Беку **«В ДОЛГ»** → CTA «Сплит · оплатить 800 000» → PIN.
7. **QR-экран** — реальный QR ссылки `zap.uz/s/481-FRD`, «Отправить SMS» (Web Share) / «Скопировать ссылку».
8. **Живой статус** — через ~6 с «Али открыл ссылку», через ~14 с «Али оплатил 400 000» (тосты + анимация строк). Либо нажмите **«Покрыть остаток»** — доля Али станет долгом.
9. **Сплит закрыт** — конфетти, +60 000 групповой кэшбэк, «Всего у Friday Crew · 205 000» → «Сохранить группу» → экран кэшбэка (+60 000 каунт-ап, Бек — после возврата долга).
10. **Главная** обновилась: кэшбэк 205 000, новый долг Бека, история пополнилась. Активный сплит показывается плавающим пиллом внизу.
11. **`/s/481-FRD`** — страница участника («Ислам просит вашу долю», выбор суммы, PIN — любой). Есть дев-переключатель «смотреть как» (Али/Бек).
12. **Долги** — «Напомнить» (кулдаун 30 с), «Напомнить всем». **Профиль → «Выйти»** — полный сброс демо к сид-данным.

Автопрогон этого сценария: `pnpm dev`, затем `SHOT_DIR=./shots/ node scripts/smoke.mjs` (плюс `smoke2.mjs` — пилл/участник, `smoke3.mjs` — покрытие остатка/сброс). Нужен установленный Chrome или Edge.

## Дизайн-референс и паритет

Эталон — `source/Copy of Приложение СПЛИТ оплат/zap-bundle-src.dc.html` (25 экранов). `node scripts/extract-design.mjs` разворачивает его в `design-reference/` (standalone-страницы + PNG-эталоны), `node scripts/parity.mjs` снимает все экраны приложения и складывает пары `<id>-app.png`/`<id>-ref.png` для сравнения. Экраны приложения собраны 1:1 по инлайн-стилям эталона.

## Где подключается реальный бэкенд

Весь «сервер» — это `src/mocks/`:

- **`api.ts`** — единственный интерфейс данных: авторизация, создание сплита, оплата долей, покрытие остатка, долги, кэшбэк, группы, карты. Все функции асинхронные с латентностью 250–700 мс — стора и страницы уже написаны под сетевые вызовы. Реальный бэкенд подключается заменой реализации этого модуля при сохранении сигнатур.
- **`seed.ts` / `db.ts`** — сид-данные и персистентность в `localStorage` (`zap:db:v1`, `zap:session:v1`). У реального API этот слой исчезает.
- **`events.ts`** — симулятор реального времени (таймеры «открыл ссылку → оплатил»). В проде заменяется WebSocket/SSE-подпиской, эмитящей те же события в `src/lib/bus.ts` — UI-слой менять не придётся.

Доменная логика, которая уже работает по-настоящему: доли поровну/вручную/по позициям с округлением до 1 000 UZS, долги при покрытии чужой доли, начисление кэшбэка (×2 при группе от 2 человек у партнёров), обновление группового кэшбэка, генерация истории по каждому действию.

## Структура

```
src/
  app/        # App.vue (транзишены роутов, тосты, пилл), router
  entities/   # types.ts + Pinia-сторы (user, splits, groups, debts, cashback, history, contacts, draft)
  mocks/      # мок-API, сид, симулятор событий
  pages/      # 18 экранов — по файлу на роут
  components/ # InvisibleDigits, AmountField, PinSheet, BottomSheet, StoryProgress, MemberRow, ActiveSplitPill, QrCode… + ui/
  lib/        # strings.ts (все строки RU), format.ts (деньги/телефоны/даты), haptics, bus
  styles/     # Tailwind + анимации (все — transform/opacity, prefers-reduced-motion учтён)
```

Дизайн-токены — в `tailwind.config.ts`: `lime #DDFF33`, `ink #111110`, `cream #EFEDE6`, `paper`, `sand`, `stone`, `muted`, `faint`, `deep`; Manrope для UI, JetBrains Mono для сумм (`1 200 000`) и мон-лейблов (`КЭШБЭК ГРУППЫ`).
