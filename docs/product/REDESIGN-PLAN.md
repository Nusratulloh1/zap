# Редизайн ZAP! — план работ

Источник: `Перерисовка ZAP экранов (1).zip` — 11 экранов в `ZAP Screens.html`,
отдельный прототип главной с лентой (`ZAP Home Prototype.html`) и 80 ассетов.

Решения руководства по итогам разбора: ставки кэшбэка ступенчатые — да;
категорию заводим у мерчанта; ленту делаем один в один по макету; экран чека
после оплаты — да; порядок работ последовательный; сначала мобильный, потом
веб; ассеты берём из макета; «Zарни/Zарабатывай» — только для русского.

- Общий экран: «ЗА МЕСЯЦ +24 500», ПОТРАЧЕНО, «СТАВКА до 3%», «ПО ГРУППАМ»,

### Сплит и чек
Живой сплит: лента событий внутри (пинги, реакции), «Дать в долг», «Добавить
фото 📸». Новый экран чека после оплаты: «ОПЛАТА ПРОШЛА», заказ, транзакция
`ZAP-8F2K-481`, карта, «Кэшбэк группе +12 000», кнопки «Закрыть» и «Вернуться

### Профиль
Совпадает с тем, что уже сделано (уровень, ранг, полоса опыта, ачивки, итоги
месяца, любимый сплит). Правок не требует.

## 2. Backend: что нужно добавить

Одна миграция закрывает всё.

```prisma
model Merchant {
  category MerchantCategory @default(other)   // НОВОЕ
}

enum MerchantCategory {
  food        // рестораны, фастфуд
  coffee      // кофейни
  grocery     // продукты
  utilities   // коммуналка
  taxi        // такси и транспорт
  shopping    // покупки
  fun         // развлечения
  other
}

model Group {
  cashbackRateBp Int @default(200)  // текущая ставка, б.п.: 200 = 2%
}
```

Ступени ставки держим в коде (`cashback/tiers.ts`), а не в БД: пороги —
продуктовое решение, меняются чаще схемы.

```ts
const TIERS = [
  { pool: 0,      bp: 200 }, // 2%
  { pool: 25_000, bp: 250 }, // 2.5%
  { pool: 50_000, bp: 300 }, // 3%
]
```

Ещё:
- `/payments/pay` возвращает `txId` (он уже есть в провайдере — нужно
  прокинуть в ответ) и `cashbackGroup`.
- `/feed?cursor=` — лента: события своих сплитов, компаний и кэшбэка,
  постранично. Собираем из `HistoryEvent` + событий компаний.
- `/bootstrap`: у мерчанта отдаётся `category`, у группы — `rateBp` и
  `nextTier`.

Категории существующим мерчантам проставит скрипт по названию (тот же словарь,
что в `merchantTheme`), дальше их задаёт партнёрская панель.

## 3. Порядок работ

Каждый шаг заканчивается сборкой и установкой на телефон — проверяем и идём
дальше.

1. **Фундамент** — миграция (категория, ставка группы), ступени ставок,
   `txId` в ответе оплаты, `/feed`, отдача новых полей в `/bootstrap`. Деплой.
2. **Главная** — приветствие, «ГОРЯЧЕЕ», компактные плитки, «Твои Crews»,
   «Где Zарабатывать», «Лента» с фильтром и подгрузкой.
3. **Долги** — топ‑3, остальные, «Напомнить всем».
4. **Кэшбэк** — экран группы со ступенью и вкладом участников; общий экран с
   месяцем, ставкой, группами и топ‑мерчантом.
5. **История** — аналитика: расход, категории, «с кем тратишь», «чаще всего».
6. **Чек оплаты** — экран после оплаты.
7. **Ассеты** — новые стикеры и медали из макета.
8. **Веб** — повторяем то же после мобильного.

## 4. Что уточнить до шага 1

- Пороги ставок: 2% → 2.5% на 25 000 → 3% на 50 000 — так? И считаем по
  накопленному пулу компании за всё время или за месяц?
- Список категорий выше закрывает макет? «Коммуналка» и «Такси» у нас пока не
  мерчанты — их будут заводить в партнёрской панели?
- Лента: показываем события только своих компаний (кто в них состоит) или
  вообще всех контактов?
