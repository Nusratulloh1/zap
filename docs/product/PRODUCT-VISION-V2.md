Дополнение к PRODUCT-VISION.md. Часть A ниже — текст руководства без правок,
часть B — разбор бенчмарков и что конкретно берём, часть C — план работ,

Главный сдвиг против V1: V1 отвечал на вопрос «какие фичи делают ZAP

# Часть A — установка руководства (без правок)

Если тебе нужен B2C-продукт именно для молодежи 16–30, я бы не брал
Revolut/Stripe как главный benchmark — они слишком “tech/premium”. Сейчас
сильнее работает сочетание clean utility + personality + social-native UI.

Мой shortlist такой:

| Продукт | Что брать |
|---|---|
| Partiful 🔥 | Главный benchmark для молодежного визуального языка |
| Cash App | Главный benchmark для B2C fintech / commerce |
| Airbuds | Social mechanics, профили, реакции, gamification |
| Daze | Смелость UI, stickers, freeform элементы, кастомизация |
| Duolingo | Gamification, progress, rewards, personality |
| BeReal / Locket | Простота + ощущение “это приложение для друзей” |
| Revolut | Только структуру сложного продукта и информационную архитектуру |

**№1 — Partiful.** Я бы сейчас очень внимательно смотрел именно на Partiful.
Apple прямо относит его к приложениям с bold Gen Z aesthetic / digital
maximalism: dopamine colors, expressive animations, memes, animated posters.
У него правильное ощущение: не банк → не SaaS → не corporate app → а digital
lifestyle product. Что брать: огромную типографику; нестандартные карточки;
эмодзи и reactions как часть UX; motion; full-screen visual moments;
colorful assets; personalization; минимум “формочек”; интерфейс иногда
специально нарушает классическую сетку.

**№2 — Cash App.** Если твой продукт касается денег, платежей, rewards,
merchant'ов, покупок — это, пожалуй, лучший базовый benchmark. Здесь бери не
“веселье”, а фундамент: 90% интерфейса — супер clean, 10% — абсолютный
визуальный удар. White/Black base, один acid brand color, огромные цифры,
минимум текста, очень крупные CTA, occasional 3D / illustration / motion.

**№3 — Airbuds.** Social product for Gen Z & Alpha: playful, raw UI, визуально
нативный TikTok/youth culture. Интересное: avatars повсюду; reactions;
stickers; friends-first UX; compatibility; “roast me” mechanics;
weekly/yearly recaps; персональный Space; интерфейс одновременно
product + meme. Benchmark для ощущения «мои друзья уже здесь» вместо
«я пользуюсь очередным сервисом».

**№4 — Daze.** Обычный messaging UI превращён в canvas: сообщения можно
двигать, менять шрифты, цвета, добавлять drawings, GIFs, backgrounds. Не
копировать хаос целиком, но взять философию: **UI itself can be content** —
интерфейс настолько необычный, что человек хочет сделать screenshot и
отправить другу.

**№5 — Duolingo.** Не visual benchmark, а behavioral UX:
streak → progress → reward → celebration → social status → comeback.
Приложение постоянно даёт маленький эмоциональный feedback вместо сухого
“Success”.

**Микс для ZAP:**

- 40% Cash App — структура, чистота, typography, navigation
- 30% Partiful — цвет, personality, visual moments, animation
- 20% Airbuds — social layer, avatars, reactions, friends, gamification
- 10% Daze — controlled chaos, unexpected interactions, stickers

Визуально уходим от «white screen → title → 4 cards → bottom nav» к:
bold typography, asymmetric cards, people/avatars, stickers, contextual
emojis, oversized CTAs, full-screen moments, subtle haptics, highly animated
transitions, one recognizable brand color, **personalization everywhere**.

# Часть B — разбор бенчмарков (исследование)

Что подтвердилось по открытым материалам и что из этого практично для ZAP.

## Partiful — «digital maximalism»

Apple в редакционной подборке действительно выделяет Partiful за bold Gen Z
aesthetic: dopamine-цвета, выразительные анимации, мемы, анимированные
постеры. Приём, который переносится на ZAP напрямую: **простая утилитарная
задача (позвать людей / поделить счёт) упакована как событие, а не как
форма.** У них — постер вечеринки, у нас — счёт компании: обложка сплита,
живой прогресс, реакции.

Практично для нас: огромная типографика заголовков (у нас уже есть Manrope
ExtraBold — использовать смелее), full-screen моменты (Everyone Paid, Recap —
уже есть, держать планку), меньше «формочек» в настройках.

## Cash App — фундамент

Формула «90% clean / 10% удар» — это ровно то, как собран наш HomeScreen
(тёмный герой + чистый светлый лист). Держать: один кислотный цвет (#DDFF33),
огромные цифры сумм, крупные CTA-пилюли. Не тянуть в каждую карточку
«веселье» — удар работает, только когда вокруг чисто.

## Airbuds — профиль как игровая карточка

По открытым разборам их Profile UI: аватары везде, реакции, стикеры,
плавающие элементы, weekly recap. Ключевой перенос в ZAP: **профиль — не
настройки, а витрина личности**: аватар на всю шапку, бейджи-ачивки как в
игре, статистика как персонаж-стата.

## Daze — контролируемый хаос

Философия «UI сам по себе контент» у нас уже частично живёт (стикеры, темы
заведений). Дозировать: один-два freeform-элемента на экран, не больше.

## Duolingo — поведенческий слой

Цепочка «progress → reward → celebration → status» у нас разложена в
milestone'ы (§B6), random moments (§C10) и титулы (§C12). Чего не хватает —
**постоянной видимости статуса**: титулы должны быть на виду в профиле как
коллекция, включая ещё не открытые (locked-состояние — половина мотивации).

# Часть C — план работ

Начинаем с профиля (решение руководства).

## C1. Профиль = игровая карточка игрока  ← ПЕРВОЕ

Референс — профиль игрового приложения (скрин от руководства): большой
аватар по центру, статы по бокам, ряд ачивок-шестиугольников, всё открыто
сразу без подменю.

1. **Аватары.** 10+ вариантов на выбор пользователя (свои иллюстрации из
   assets: персонажи + фирменные стикеры). Выбор — прямо в профиле, тап по
   аватару → сетка. Выбор сохраняется и виден везде, где показывается «я».
2. **Ачивки как в игре.** Титулы (§C12) — горизонтальный ряд бейджей:
   открытые — цветные, неоткрытые — серые с замком. Все шесть видны всегда:
   locked-состояние мотивирует сильнее, чем пустота.
3. **Всё открыто сразу.** Иконки приложения — инлайн-ряд из трёх превью с
   галочкой, без шита. Язык — инлайн-переключатель из трёх пилюль. Никаких
   «нажми, чтобы увидеть ещё один экран».
4. **Wow-вход:** шапка профиля — тёмная сцена с точечной сеткой (как герой
   главной), большой аватар с лаймовым кольцом, появление с пружиной.

## C2. Следующие шаги (после профиля)

- Обложки сплитов (Partiful-постер → счёт компании)
- Реакции крупнее и в большем числе мест (Airbuds)
- Полноэкранное празднование milestone'ов вместо карточки (Partiful moments)
- Аватар в шапке главной — тоже выбранный, не буква

## Чего НЕ делаем

- Не ломаем платёжные сценарии ради «веселья» — деньги остаются 90% clean
- Не вводим второй акцентный цвет
- Не копируем хаос Daze в экраны с деньгами
